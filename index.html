Evaluation · Browser agent

Browser Agent Reliability on Yelp

A browser agent that finds restaurants on Yelp, tested on 40 hand-scored runs. It claimed success every time but was wrong a third of the time. A stricter prompt made it 2.5 times cheaper but over-cautious; letting code make the final choice from the agent's own list reached 80% correct at 40% of the cost.

Tests 5 LLMs on 20 hard questions about IPL cricket data. Each model's SQL is run on the real database and its answer compared to a hand-written answer key. The best model scored 17/20.
